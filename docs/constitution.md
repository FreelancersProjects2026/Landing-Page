# Constitución del proyecto

## 1. Problema
Los clientes necesitan software que responda a su realidad operativa y aporte valor concreto a su negocio.
## 2. Solución
Somos tres profesionales que diseñamos soluciones a medida, adaptándonos a cada cliente y comprendiendo primero su dominio mediante DDD.
## 3. Stack tecnológico
El proyecto será exclusivamente frontend y utilizará React como tecnología principal.
## 4. Relación entre especificación y código
Toda implementación deberá corresponder con una especificación clara, trazable y actualizada.
## 5. Separación de capas
La interfaz, la lógica de aplicación y el dominio permanecerán desacoplados y con responsabilidades bien definidas.
## 6. Pruebas unitarias y TDD
El desarrollo seguirá TDD: cada comportamiento se definirá primero con una prueba unitaria y después se implementará el código mínimo necesario.
## 7. Consistencia de datos
Los datos deberán validarse y mantenerse coherentes en todos los flujos, estados y límites de la aplicación.
